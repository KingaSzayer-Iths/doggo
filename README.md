# Doggo

Doggo is a responsive web application for dog owners, designed to inspire an active and social life with dogs. The application provides information about activities, training, dog-friendly places and useful tips in a clean and responsive interface.

The project was built with **React**, **TypeScript** and **Vite**, with a strong focus on responsive design, usability and accessibility.

---

## Live Demo

https://doggocommunity.netlify.app/

---

## Features

- Responsive design (mobile, tablet and desktop)
- Multi-page navigation with React Router
- Activity cards
- Tips & inspiration pages
- Static map section
- Responsive card layouts
- Mobile navigation
- Hover animations and micro interactions
- Accessibility improvements (ARIA, semantic HTML, alt text)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/doggo.git
```

### Navigate to the project

```bash
cd doggo
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

## Accessibility

The project includes several accessibility improvements, including:

- Semantic HTML
- ARIA attributes
- Skip link
- Alt text for images
- Keyboard navigation
- Visible focus states

---

## Responsive Design

The application was developed using a **mobile-first** approach and adapts to different screen sizes using CSS Grid, Flexbox and media queries.
